CONTEXT

Design a left sidebar for a dark fantasy D&D web application.

The sidebar should function primarily as:

Clean navigation system

Compact information dashboard

It must feel structured, modern, efficient and easy to scan.
No heavy fantasy ornaments.
No game HUD overload.
Minimalist dark fantasy tone.

GENERAL STYLE

Dark UI with depth

Subtle gradients

Clean spacing

Soft shadows

No cartoon elements

No medieval decorative frames

Design should feel like:

A magical control panel for an intelligent strategist.

COLOR SYSTEM

Use:

Background: #1C1B22
Slightly lighter panel surface: +4–6% brightness
Accent: #6C5CE7
Gold accent (very subtle): #C6A75E
Text primary: #E0E3EA
Text secondary: #B8BCC8

Avoid pure black and pure white.

1️⃣ SIDEBAR CONTAINER

Full height vertical panel

Slightly lighter than main background

Soft inner shadow on right edge

Border radius only on internal cards (not whole sidebar)

Width should feel stable and structured.

2️⃣ HEADER (Adventure Panel)

Top section:

Title: “Adventure Panel”

Slightly larger font than body

Subtle gold underline separator (1px, low opacity)

Good vertical spacing

3️⃣ TOP NAVIGATION (Stats / Quests / More)

Design as segmented control (horizontal tabs).

Each tab:

Icon on the left

Label on the right

Rounded container (12px radius)

Soft dark background

Active state:

Violet background (#6C5CE7)

Text brighter

Slight inner shadow

Subtle transition

Hover state:

Background slightly lighter

Soft brightness change

No glow overload

Transition between tabs:

Smooth fade or slide (subtle)

4️⃣ STATS VIEW (Primary Stats Section)

Section title:

“Primary Stats”

Slight gold accent for title

Clear spacing from content

Stat list layout:

Two-column structure:
Label (left)
Value (right aligned)

Requirements:

Values use fixed-width alignment

Numbers visually stronger than labels

Consistent vertical spacing

Clean row separation (very subtle divider)

Optional UX enhancement:

Add subtle horizontal indicator bar beside each stat:

Neutral grey tone

Not colorful

Minimalistic

Low contrast

Hover on each stat row:

Slight background lift (3–5%)

Cursor pointer

Optional tooltip support

No glow effects.

5️⃣ QUESTS VIEW (Active Quests + Rumors)
Active Quests Section

Title:
“Active Quests”

Each quest item:

Compact card style

Soft border

Rounded corners (12px)

Subtle shadow

Inside:

Quest title (stronger text)

Short description (secondary text)

Clean spacing

No heavy decoration

Hover state:

Slight elevation

Border becomes slightly brighter

Optional:
Subtle quest category indicator (tiny gold dot or side accent).

Rumors Section

Title:
“Rumors”

Instead of plain text:

Use structured list layout

Bullet icons instead of dots

Clear vertical spacing

Slight background contrast block

Text should be readable and scannable.

No long paragraph style.

6️⃣ MICRO INTERACTIONS

Apply consistently:

Hover = slight brightness increase

Active tab = solid violet

Focus = thin violet outline

Smooth transitions (150–200ms)

No dramatic animations.

7️⃣ SPACING SYSTEM

Use 8px grid system.

Spacing rhythm:
8 / 16 / 24

Clear separation between sections.

Avoid visual clutter.

8️⃣ DESIGN RULES

Prioritize readability

Prioritize structure

Prioritize scan speed

No visual chaos

No decorative fantasy overload

No inventory section in this layout

This sidebar must feel:

Calm. Structured. Powerful. Intelligent.
