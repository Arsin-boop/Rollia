🔮 CONTEXT

Design a dark fantasy D&D-inspired web application interface.

This is a desktop layout with three columns:

Left panel: Character stats

Center: Dungeon Master narrative panel

Right panel: Character profile and progress

Bottom: Input command field

The style must feel atmospheric, premium, immersive — but still clean and readable like a modern web app.

No cartoon style.
No medieval overload.
Subtle, elegant fantasy.

🎨 COLOR SYSTEM

Use a 4-color system:

Background (Obsidian):
#1C1B22

Accent (Arcane Violet):
#6C5CE7

Gold Accent (Ancient Gold):
#C6A75E

Text (Mist Silver):
#B8BCC8

Add soft gradients and depth.
Avoid pure black and pure white.

🧱 LAYOUT REQUIREMENTS
1. Background

Dark gradient background

Very subtle radial light in center

Light noise texture (almost invisible)

2. Left Panel (Stats)

Slightly lighter than main background

Soft inner shadow

Minimalistic stat list

Add subtle icons for attributes (strength, intelligence, etc.)

Hover state for each stat (slightly brighter background)

3. Center Panel (Dungeon Master Message)

Floating card in the center

Dark violet background

12–16px border radius

Soft outer glow

Thin gold border (very subtle)

Elevated shadow

Text:

Slightly brighter than regular text

Comfortable line-height

Elegant spacing

No avatar for Dungeon Master.

4. Right Panel (Character Profile)

Top:

Character card with gradient violet background

Soft shadow

Gold separator under name

Level indicator styled in gold

HP / MP / XP:

Styled progress bars

HP: deep red accent

MP: cool blue-violet

XP: gold

Soft inner shadow inside bars

Status Effects:

Pill shape (fully rounded)

Thin border

Soft glow on hover

Color-coded per type

5. Bottom Input Field

Dark container

Rounded corners

Subtle border

Focus state:

Violet glow

Border becomes brighter

Slight animation feel

Add small dice icon button on the right side of input.

✨ DESIGN STYLE RULES

Modern UI meets dark fantasy

Soft shadows, no harsh contrasts

Balanced whitespace

Elegant minimalism

Cinematic lighting feeling

No heavy medieval textures

This should feel like:
“A magical command terminal for a dark fantasy world.”

🚫 AVOID

Cartoon UI

Heavy ornament frames

Too much gold

Too much glow

Bright saturated colors

Game HUD overload
